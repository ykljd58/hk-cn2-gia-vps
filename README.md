## 二十兆带宽到底能跑多少

带宽和实际下载速度的换算是固定的：Mbps 除以 8 就是 MB/s。

- 20Mbps ≈ 2.5MB/s
- 30Mbps ≈ 3.75MB/s
- 50Mbps ≈ 6.25MB/s

2.5MB/s 是什么概念？一个 2MB 的网页，理论加载时间不到 1 秒；WordPress 后台操作、API 请求、SSH 管理这些轻量场景完全感觉不到瓶颈。但如果你的站要传图片、放视频，或者有几个人同时下载文件，2.5MB/s 会立刻成为短板。

按用途分：

- 个人博客、展示型外贸站、轻量 API 后端：20Mbps 够，500GB 月流量对月访问几千到几万 PV 的站点也够
- 电商独立站（WooCommerce、Shopify 后台）、有图片和产品视频：30Mbps 更稳，1TB 流量留出余量
- 代理、中转、多人共用：流量消耗远高于建站，直接看不限流量档
- 视频、下载站、直播推流：20–30Mbps 都不合适，这类需求要的是 100Mbps 以上的大带宽方案

## 怎么确认买到的真是 CN2 GIA，而不是“优化”两个字

这是本文最该讲清楚的一点。搜索词里带 CN2 GIA，但商家页面上写的往往是“优化线路”“精品线路”“Premium”这类模糊表述，两者不能直接画等号。

CN2 是中国电信的下一代承载网，内部分两档。GT 相当于普通快车，高峰期仍会波动；GIA 全程有 QoS 保障，去回程独立带宽，这才是多数人搜“CN2 GIA”时真正想要的那条。现在市面上还有一种做法是三网分运营商优化：电信去程走 CN2 精品、联通走 9929、移动走 CMIN2 或 CMI，三网回程走大陆优化直连。恒创的实测路由就是这个结构，电信从上海网口出去走 59.43 的 CN2 GIA，联通从广州走 AS4837，移动从上海走 CMI 骨干网。

LightLayer 页面上的“优化线路”“Premium 优化”，公开资料里没有直接写明是 CN2 GIA 还是三网优化，也没有给出测试 IP 和路由截图。这种情况下不要相信任何“超低延迟”的宣传，自己验：

1. 下单前向客服要测试 IP，或用最低档月付先开一台
2. 从自己所在城市做双向 MTR，去程和回程都要看
3. 电信方向看是否出现 59.43 段的 CN2 节点，且去回程都走
4. 联通看是否走 9929 或 AS4837，移动看是否走 CMI
5. 晚高峰（20:00–23:00）再测一次，丢包和延迟抖动比空闲时段更能说明问题

关于延迟，香港到大陆的合理区间是 40–60ms，第三方实测口径大多落在这个范围（恒创全国三网平均 42ms、本地 57ms；丽萨导购文给的是 40–60ms）。有商家宣称“大陆延迟 5–22ms”，这个数字和香港的物理距离对不上，也和它自己页面里“香港 5–15ms”的表述矛盾，不建议当作决策依据。看到低于 20ms 的宣传，一律用测试 IP 自己复核。
